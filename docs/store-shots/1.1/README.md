# App Store 商店截图（1.1 版）

三套语言的手机截图，以及给 ASC 上传用的 1179×2556 版本。

## 目录

```
1.1/
├─ cn/                        简体中文  6 张（IMG_0057 · 0059 · 0060 · 0061 · 0062 · 0063）
├─ en/                        英文      6 张（IMG_0064 … 0069）
├─ tr/                        繁体中文  5 张（IMG_0052 … 0056）
└─ make_upload_sizes.py       转换脚本
```

原始截图是 **828×1792**（iPhone 11 级 2x）。App Store Connect 的
「6.1 寸显示屏」槽位要求 **1179×2556**，所以上传要用 `upload-1179x2556/` 里的版本：

```
1.1/<lang>/upload-1179x2556/*.png      ← 这个才是能直接拖进 ASC 的
```

## 转换怎么做的

```
828 / 1792 = 0.46205
1179 / 2556 = 0.46127      ← 比例只差 0.17%
```

所以**先按高度放大到 2556**（1.43×，LANCZOS），再把多出来的 1 列居中裁掉 ——
**不拉伸、不变形**；放大后补一次轻度反锐化（`UnsharpMask(1.2, 55%, 2)`），
避免小字发虚。输出统一 RGB、无透明通道（ASC 不需要 alpha）、单张 < 8 MB。

## 用法

```powershell
cd docs\store-shots\1.1
python make_upload_sizes.py           # 三个语言全转
python make_upload_sizes.py cn        # 只转简体
```

脚本幂等：重跑会覆盖 `upload-1179x2556/` 里的同名文件，并逐张打印
`宽x高 / 文件大小 / PASS|FAIL`。

## 其它尺寸（需要时）

| 槽位 | 尺寸 |
|---|---|
| 6.1 寸（当前）| **1179 × 2556** |
| 6.9 寸 | 1320 × 2868 |
| 6.5 寸 | 1242 × 2688 |
| 5.5 寸 | 1242 × 2208 |

要别的尺寸，改脚本顶部 `TARGET_W / TARGET_H` 两行即可（等比放大 + 居中裁边）。

> 营销素材（标题图 / 搜索结果图）在 `../marketing/`，由 `../marketing/make_marketing.py`
> 生成，与本目录不同用途：那些是产品页的展示图，不是截屏槽位。
