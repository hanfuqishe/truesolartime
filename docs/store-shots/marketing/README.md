## 3. 安全区是怎么算的

产品页 hero 居中横裁时，被切掉的是**左右两侧**，所以判据只看横向：

```
安全区   x ∈ [W/2 − W·safe/2 , W/2 + W·safe/2]
16:9 / 3:2 搜索图  safe = 0.60   → 占画面 20%..80%W
超宽标题图          safe = 0.50   → 占画面 25%..75%W
```

- 文字宽度**不是估算**：`center_runs()` 逐 run 用 `font.getlength()` 累加，返回真实墨迹横坐标区间；
- 卡片宽度同样按 `card_w` 算真实 box；
- 每张图生成时会打印实测区间并断言，例如
  `title 5244x2950: text 28.9%..71.1%W  card 37.0%..63.0%W  safe ±30% (20%..80%W)  PASS`。

实测结果（都在安全区内，留 8~9 个百分点余量）：

## 5. 卡片裁切的定位方式

卡片内容不是从截图顶部开始，而是**自动对准 App 主卡片的顶边**：

- `detect_card_top()` 从截图 5% 高度处开始逐行取 `x∈[10%,90%]` 的**中位色**（中位数对页头文字稳健），
  与首行页面底色比较，连续 3 行色差 ≥ 8 即判定进入主卡；
- 01.png 实测主卡上沿 `y=353`，向上留 `CROP_PAD=4`px，即从 `y=349`（截图高度 13.65%）裁；
- `card_shot()` 直接把源图裁到该处再缩放，所以卡片顶部就是主卡上沿，不会出现半截页头；
- 需要人工指定时把 `CROP_TOP_OVERRIDE` 设为截图像素坐标（`None` = 自动检测）。
