## 2. 主截图：`asc-6.1-final/01.png`（香港 · 夜间主题 · 繁体界面）

- **地址干净**：`香港特別行政區油尖旺區`，比 04（迪拜）混排阿拉伯文的地区名清爽；
- **时差更有说服力**：真太陽時 19:18 vs 標準時間 19:26（**差 8 分钟**），04 只有 4 分钟；
- **配色同系**：夜间深蓝界面与标题图背景（`#0B1220 → #16203A`）同色系，画面统一；
- 界面为繁体（`真太陽時時鐘` / `標準時間` / `戊時 · 初`），与图内繁体文案一致。
- 图内数字全部取自该截图的真实读数：**真太陽時 19:18 / 標準時間 19:26**（不编造）。

> 换主图：改脚本顶部 `SHOT_FILE` / `NUM_TRUE` / `NUM_STD` 三行后重跑即可
> （例如换回 04.png 就是 15:28 / 15:32），版式、裁切线、字号全部自动适配。

## 3. 卡片裁切的定位方式

裁切起点不再是「截图高度的百分比」，而是**自动对准 App 主卡片的顶边**：

- `detect_card_top()` 从截图 5% 高度处开始逐行取 `x∈[10%,90%]` 的**中位色**（中位数对页头文字/图标稳健），
  与首行页面底色比较，连续 3 行色差 ≥ 8 即判定进入主卡；
- 01.png 实测主卡上沿 `y=353`，再向上留 `CROP_PAD=4`px，即**从 y=349（截图高度 13.65%）开始裁**；
- 结果是卡片内容从主卡顶部干净开始，不会留下半截 App 页头或标题残影；
- 需要人工指定时把 `CROP_TOP_OVERRIDE` 设为截图像素坐标即可（`None` = 自动检测）。

## 4. 版式要点

配色与 App 完全一致：背景 `#0B1220 → #16203A`（搜索图更暗：`#070C16 → #10182E`）；
金色强调 `#F5D68A`；正文 `#E8EDF7`；次级文字 `#9AA7BF`；分隔点 `#4A5670`。

### 标题图（16:9 与超宽）

- 背景：深蓝对角渐变 + 右上角金色径向光晕（背景层 12%）；因为夜间截图与背景同色系、背景层光晕会被卡片挡住，
  另在最上层用 `ImageChops.screen` 加一层**很淡的加光**（9%，仍 ≤12%），保证「右上角金色光晕」在实际画面里可见。
- 左文案区（≤ 42% 宽，统一左边距 **6.0% W**，全部 ≥ 5% W）：
  金色短横线 → 主标题「真太陽時時鐘」（雅黑粗体）→ 副标题「即時定位顯示目前真太陽時」→
  一行读数「真太陽時 **19:18** · 標準時間 **19:26**」（数字加粗，真太阳时用金色）→ 卖点行「日出日落 · 上中天 · 逐時天氣 · 十二時辰」。
- 右侧：同一张截图放进圆角卡片，圆角 = **0.04 × 卡片宽**，白色 **8%** 描边，高斯阴影（半径 ≈ 0.008 W）；
  卡片宽 39.5% W（16:9，左沿 61.7% W）/ 36% W（超宽，左沿 65.2% W），上下出血并向右出血 1%。
- 未放 `iOS` 字样（保留干净），全部文字由代码绘制。

### 搜索结果图（16:9 与 3:2）

- 背景同上但更暗（顶层加光 6%）；左 1/3 只放「真太陽時時鐘」+ 一小行「真太陽時 · 隨身時鐘」，右边 2/3 是同一张截图卡片。
- 卡片左沿：16:9 = 65.0% W；3:2 与小尺寸 = 63.5% W（这两档画布更「方」，卡片要略放大，
  底部才能整块出血、圆角完全出画）。

### 横版截屏占位

- 截图**原样居中**（不旋转、不拉伸，0.84 × H 高），左右用背景渐变填充，避免大面积空白。
- 左侧竖排金色「真太陽時」、右侧竖排白色「標準時間」（对应 App 里金色真太阳时 / 白色标准时间），逐字居中排布。
- App 只支持竖屏，这两个槽位在 App Store Connect 通常留空；此处按需求仍生成占位图。
