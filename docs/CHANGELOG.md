# 变更记录（CHANGELOG）

按主题归类，最近在前。提交粒度见 `git log`；这里只记录**用户可感知的变化**与**踩过的坑**。

---

## 2026-11-19（上午 ~ 中午）

### 境外地图可用性

- **Android / 鸿蒙**：境外自动底图改为 **ESRI 街道图**（`server.arcgisonline.com` 走 Akamai，国内可直连）；
  优先级 ESRI → OSM → 高德 → z3 全球图；手动选项新增「Esri 街道图」。
- **iOS**：自动底图改为 **Apple 地图**（MapKit 系统底图，不挂 overlay、不探测、不回退）；手动选项新增「Apple 地图」。
- **修的 bug**：选新加坡却走高德 —— `MapStyle.effective` 用了 **GCJ-02 偏移边界**（纬度下限 0.83°）判断“境内”，
  把整个东南亚算进中国；改用 `SolarTimeMath.isInChinaRegion`（国家码优先，无码则 73–135°E / 18–54°N）。

### 天气（iOS）

- 接入 **Apple WeatherKit**：自动 = WeatherKit → Open-Meteo → 7Timer!；手动可切 WeatherKit / Open-Meteo。
- WeatherKit 的 **App ID capability 只能手工开**（ASC API 拒绝 `capabilityType=WEATHERKIT`），
  开完描述文件即带 entitlement；已写入 CI 脚本的提示里。
- **官方署名**：Apple 要求显示标识图 + 法律页链接；先后试过「卡片页脚 → 卡片底部 → 最终放到设置页「关于」」
  （苹果自己的天气 App 也不在卡片上贴标识）。
- 修的 bug：`loadIfNeeded()` 从未被调用 → 标识 URL 恒 nil → 永远显示文字；WeatherKit 成功后**没落盘** → 诊断显示 Open-Meteo。

### 太阳圆盘标签

- 三个时间标签加文字说明：`日出 06:24` / `日落 16:55` / `上中天 11:39`。
- **南半球标签移到地平线下方**（昼弧在上、夜弧在下，几何上不可能压线）。
- 近极昼（南极中山站 11/19，白昼 22h42m）三标签重叠 → 以交点为基准最小推开；真重合才退画布边缘。
- 修的 bug：iOS `SunCard` 把对齐写死成 `.trailing`/`.leading`，南半球镜像后文字朝**圆内**展开压在弧线上。

### 顶部标签行（四档退化）

- 三端统一：档 0 左右两半 + 竖线 → 档 1 去「真太阳时」→ 档 2 去时区 → 档 3 省略号；
  **竖线只在档 0 上延**；**地名恒 12，不缩字号**（缩字号不好看，且三端观感不一）。
- 修的 bug：
  - 鸿蒙丢了左右两半结构（早前为修长地名改成单行全宽）；
  - 鸿蒙按**半栏宽**算可用空间（档 1/2/3 已是整行宽）→ 香港这类放得下的名字被缩到 9fp；
  - 鸿蒙 **px/vp 单位混用** → 可用宽算大 → 档 0 文字被静默截断（`Bilecik, …`）。

### 地名反查

- 流程：首帧占位（预设城市用本地名、GPS/手输用 `--`）→ Apple 反查 → 5 秒并行 Nominatim → Apple 后到覆盖；
  两家都失败才显示 `-`。
- **改用 5 km + 30 天 + 60 s 规则**（与 Android 一致）：同城走动不重查，换城市立即查。
- 修的 bug：`-1001` 其实是 **CLGeocoder 被反复调用限流**；换地点时也常常撞在 3 秒窗口里被拒。

### 常用城市

- 三端等宽网格：Android 3 列（P60 类机型 4 列会截断城市名）、鸿蒙 4 列、iOS 天然等宽。

### 地图卡署名

- 底部只留署名，删掉「N 级」「双指缩放」「按所在地区自动选择」；`contributors` 本地化为「贡献者 / 貢獻者」。
- 修的 bug：选 OSM 后署名仍是 Esri 串（署名只在瓦片加载完成后才更新）→ 改为样式一变**同步**切换。
- 手动底图瓦片改为分批并行（并发 4）。

### 文档

- `docs/AGENTS.md` 新增第 7 节（两套「中国」边界不能混用）与第 8 节（太阳圆盘标签布局的三端红线）。


## 2026-11-19（下午）

### 地名反查（三端统一）

- **改成「按地点换代」**：新地点一律直接发请求，旧结果按代号（generation）丢弃 ——
  修「上一次查询卡住 → 换城市也被挡」；Android 另修「跟随 GPS 的首次 fix 从未触发反查」。
- **节流改为按空间距离**：与上次成功坐标 ≤ 5 km 且未超 30 天沿用缓存；> 5 km / 过期 / 距离未知才重查；
  换城市走 force 立即查；GPS 采样 60 秒一次。
- 超时收紧：整体 6 秒、高德 5 秒不回调即转 OSM 兜底。
- 诊断新增：`耗时 = 0.3s · 请求次数 = 1 · 距上次反查 1.2 km · 跳过原因 …`。

### 地名显示（顶部标签行）

- 三端统一：**地名恒 12，不缩字号**；放不下只**退档**（去「真太阳时」→ 去时区 → 省略号）。
- 鸿蒙修的三个 bug：丢失左右两半结构、按半栏宽算可用空间（香港名被缩到 9fp）、
  **px/vp 单位混用**导致可用宽算大（`Bilecik, …` 被静默截断）。

### 底图署名（合规分层）

- **卡片底部**只留署名（删「N 级」「双指缩放」「按所在地区自动选择」），`contributors` 本地化为「贡献者」。
- **设置页「关于」新增「地图数据来源」**：Esri 官方 `copyrightText` 完整 14 个来源（英文原文）+ 可点击版权链接；
  OSM / 高德各自显示对应署名。
- 修的 bug：选 OSM 后署名仍是 Esri 串（署名只在瓦片加载完成后才更新）→ 改为样式一变**同步**切换。
- 鸿蒙手动底图瓦片改为分批并行（并发 4），不再逐块串行。

### 常用城市与尺寸

- 三端等宽网格：Android 3 列（4 列会截断城市名）、鸿蒙 4 列、iOS 天然等宽。
- 鸿蒙设置页顶部长地名不再压住「设置」标题（右侧限宽 + 省略号）。

### 其他

- 太阳圆盘标签的宽度估算修正（上中天 7 → 11 字符，避免低估重叠风险）。
- `docs/AGENTS.md` 新增第 9 节「异步查询用按地点换代，而不是全局单飞」。
