# 软件著作权登记材料（真太阳时时钟 V1.0）

这里是为中国版权保护中心「计算机软件著作权登记」准备的两份材料，由 `tools/make-copyright-docs.py` 自动生成。

| 文件 | 页数 | 用途 |
|---|---|---|
| `真太阳时时钟-V1.0-源程序.pdf` | **60**（前 30 + 后 30） | 源程序鉴别材料 |
| `真太阳时时钟-V1.0-软件说明书.pdf` | 7 | 文档鉴别材料 |
| 同名 `.docx` | — | 需要改动时的源文件（PDF 由 Word 导出） |

> 只提交 PDF。`docx` 留作备份与再编辑，不要把两份都传上去。

---

## 一、材料规格（已按中心要求生成）

| 要求 | 本材料的落实情况 |
|---|---|
| 源程序取前 30 页 + 后 30 页 | 60 页，取全量 4.5 万行源程序的**前 1500 行 + 后 1500 行** |
| 每页不少于 50 行（末页除外） | **每页恰好 50 行**（已用 Word 逐页核过，60/60 页均为 50 行）|
| 页眉标注软件名称、版本号 | `真太阳时时钟 V1.0  源程序（前 30 页 + 后 30 页）` |
| 页码连续 | 页脚「第 X 页」为 Word 页码域，1–60 连续 |
| 文档每页不少于 30 行 | 说明书正文行距 22pt，约 28–30 行/页，含 3 张界面截图 |

**长行不会自动折行**：生成脚本按字宽（ASCII 0.6em / 中文 1.0em，单行上限 52em）预先续行，
所以 Word 排版不会因为折行把某页顶成 51 行——这类"页数变 60 变 61"是最常见的格式驳回原因。

## 二、在线提交步骤

1. 打开中国版权保护中心「软件著作权登记系统」：<https://register.ccopyright.com.cn>
2. 注册并实名（个人：身份证 + 人脸核验）。
3. 新建申请，按下表填写：

| 字段 | 建议填写 |
|---|---|
| 软件全称 | **真太阳时时钟**（与 AppGallery / App Store 上的名称一致）|
| 软件简称 | 可留空，或填「真太阳时」 |
| 版本号 | **V1.0** |
| 开发完成日期 | 首次可发布版本的实际完成日 |
| 首次发表日期 | 若已上架则填首次上架日；未发表选「未发表」 |
| 权利取得方式 | 原始取得 |
| 权利范围 | 全部权利 |
| 开发的硬件环境 | 普通 PC（x86_64，16GB 内存）|
| 运行的硬件环境 | 手机（Android / HarmonyOS / iOS）|
| 开发该软件的操作系统 | Windows 11 / macOS |
| 软件开发环境 / 工具 | Android Studio、DevEco Studio、Xcode |
| 编程语言 | Kotlin、ArkTS、Swift |
| 源程序量 | 约 45000 行 |
| 主要功能 | 显示当地真太阳时与标准时间对照、十二时辰、日出日落与太阳高度角、逐时天气、位置地图、桌面卡片 |

4. 上传两份 PDF（源程序 + 说明书）。
5. 提交后等待受理；正常 30–60 个工作日下发证书，可在系统里查进度。

## 三、常见驳回原因（对照检查）

| 驳回 | 本材料的处理 |
|---|---|
| 源程序页数不足 60 页，或每页不足 50 行 | 恰好 60 页 × 50 行 |
| 页眉缺软件名称/版本号 | 每页页眉都有 |
| 页码不连续或缺失 | 页脚为页码域，1–60 |
| 软件名称与上架名称不一致 | 统一用「真太阳时时钟」；V1.0 与页面版本号一致 |
| 上传了 docx 而非 PDF | 只传 `.pdf` |
| 说明书是截图拼的、无正文 | 正文为中文字体排版，另有 3 张界面截图 |

## 四、重新生成

源码变动后（例如版本升到 V1.1，或想换截图）：

```powershell
python tools/make-copyright-docs.py --pdf
```

- 不带 `--pdf` 只出 docx；
- 需要 Word（脚本用 Word COM 导出 PDF 并统计页数）；
- 截图放在 `docs/store-shots/`，脚本会自动压到 900px 再嵌入（否则文档会涨到 7MB）；
- 生成后请抽查一次页数：`源程序` 必须是 **60 页**。

改版本号时，同时改脚本顶部的 `VERSION` 常量，页眉与文件名会一起变。

## 五、与上架流程的关系

```
软著证书  ─┐
           ├→ AppGallery 上架材料（版权信息页上传 PDF）
ICP 备案  ─┘
```

- 备案流程见 `docs/icp-filing.md`；
- 没有软著时，AGC 也接受《电子版权认证证书》（付费、几天出证），见该文档 §8.2。
